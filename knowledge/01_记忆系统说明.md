# 记忆系统说明

燕子的知识和记忆分为三层，各司其职：

## 第一层：即时记忆（运行时）
保存在本地运行环境中，每次对话自动加载，响应最快。
- **SOUL**：燕子的身份、性格、沟通风格
- **USER**：涛哥的核心画像和偏好
- **MEMORY**：当前重要状态锚点和长期行为规则
- **TOOLS**：工具使用经验索引
- **SECRET**：敏感凭证（不写入知识库）

## 第二层：近中期记忆（结构化文件）
保存在 `recent_memory/` 目录中，按需读取。
- 项目进度快照
- 重要决策记录
- 待办事项
- 详细经验文档

## 第三层：飞书知识库（长期沉淀）
即本知识库，保存长期稳定、需要团队共享的知识。
- 身份与灵魂 SOUL
- 涛哥档案 USER
- 公司档案 COMPANY
- 管理规则 MANAGEMENT
- 工具经验 TOOLS
- 运行记忆 MEMORY
- 待办事项 TODO

## 同步规则
当前阶段：本地运行文件与飞书知识库**不同步**，各自独立维护。
- 本地文件是燕子运行时的"主记忆"
- 飞书知识库是"对外可见的知识沉淀"
- 重要更新时手动同步两边
- 未来可建立双向同步 Workflow

## 记忆更新原则
1. 老板每次纠正或补充，判断是单次还是长期规则
2. 长期规则整理后沉淀到对应位置
3. 敏感信息不进飞书知识库，只存本地 SECRET
4. 不重复记录相同信息
