# 公司档案 COMPANY

## 业务定位
公司主要从事跨境电商业务。
- **当前核心市场**：泰国
- **当前核心平台**：TikTok Shop
- **未来扩展方向**：其他东南亚国家、其他海外电商平台、中国电商平台、更多店铺和业务模式

AI 系统、数据系统和工作流程必须具备可扩展性。

## 经营模式
多店铺运营 + 多商品测试 + 广告推广 + 达人推广 + 本地仓履约 + AI 内容生产 + 人工执行 + 自动化管理

### 基本经营链路
市场调查 → 选品 → 成本与利润测算 → 商品定位 → SKU 设计 → 标题与关键词 → 主图/副图/详情页 → 商品上架 → 商品测试 → 广告投放 → 达人推广 → 订单履约 → 客服售后 → 数据分析 → 决定放量/优化/停止

处理任何商品时，应先理解其处于链路的哪个阶段。

## 主要商品方向
### 1. 美妆个护
身体乳、护发精油、面霜、精华液、止汗露、香氛个护等
重点关注：使用场景、目标消费者、痛点、香型、容量、SKU组合、赠品机制、复购可能、合规、视觉表现、营销卖点

### 2. 女装
当前有女士裤装等商品
重点关注：版型、颜色、尺码、面料、穿着效果、泰国消费者审美、季节适用性、搜索关键词、主图点击率、SKU结构

⚠️ **商品视觉红线**：女装图片必须保证真实性，不能为了视觉效果擅自改变裤型、口袋、抽绳、面料、颜色、刺绣、腰部结构等真实产品结构。

## 商品测试逻辑
新品不能凭感觉大量投入。
流程：市场调查 → 竞品分析 → 消费者需求分析 → 成本核算 → 利润测算 → 素材准备 → 小规模测试 → 观察数据 → 决定是否继续投入

商品状态分类：值得测试 / 正在测试 / 继续优化 / 值得放量 / 继续观察 / 停止推广 / 淘汰

## 广告投放基本原则
广告投放核心目标不是单纯消耗预算，必须服务于：获得订单、验证商品、扩大有效商品、控制获客成本、保证利润。

关注指标：消耗、成交、ROI、转化、客单价、利润、退款、商品阶段
广告调整不得只根据单一时间点随意判断。

## 成本意识
商品利润分析至少考虑：
商品成本、仓库费用、物流费用、TikTok 平台费用、佣金、电商增长相关费用、基础设施费用、达人佣金、广告推广费、退款与售后损失、其他运营成本

任何关于降价、加赠、提高佣金、增加预算、扩大投放的建议，都应考虑最终利润影响。

## 商品视觉规范
- 强调：真实、清晰、商业摄影感、高点击率、高转化
- 默认主图比例：1:1
- 产品主体突出，禁止无意义拼贴，禁止九宫格
- 不得虚构产品功能，不得随意改变包装/品牌/颜色/容量/结构
- 每张图片独立完整

## 商品内容规范
- 标题兼顾：搜索词、产品属性、消费者需求、使用场景、差异化、可读性
- 泰国 TikTok Shop 商品文案优先泰语
- 避免机械翻译、关键词堆砌、虚假功效、绝对化宣传、医疗类违规表述
- 标题之间有差异化

## 客服体系
分三类：售前（产品信息/规格/活动）、物流（发货/快递/查询）、售后（少发/漏发/破损/退货/差评/申诉）
客服优先用泰语与泰国消费者沟通，要求：礼貌、简洁、解决问题、不激化矛盾

## 店铺安全原则
店铺安全优先级 **高于** 短期销量。
重点关注：违规商品、禁售商品、侵权、假冒风险、虚假宣传、高取消率、高退款率、履约异常、客服问题、差评、账号异常、资金异常

## 团队与 AI 架构
- **老板（涛哥）**：战略方向、重大决策、关键资源、最终审批
- **燕子（主Agent）**：理解、判断、协调、验收、汇报
- **专业子 Agent**：经营数据、商品/选品、广告投放、商品内容、视觉创意、客服售后、店铺风控、任务调度
- **真人员工**：需要人工判断的执行、现场工作、复杂沟通
- **工作流**：固定重复流程的自动执行

## 数据原则
真实经营数据 > AI 推测。
有数据用数据，没数据不编数据，缺数据说明缺什么。

## 自动化目标
重复发生的工作优先判断是否值得自动化：
每日数据统计、异常监控、任务下发、日报周报、广告异常、库存异常、店铺异常、客服高频问题、商品表现分类

形成路径：规则 → SOP → Workflow → 自动执行
