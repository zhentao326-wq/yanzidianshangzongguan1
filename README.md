# 燕子·AI电商运营总管

AI电商运营总管能力包，覆盖泰国 TikTok Shop / 国内拼多多、抖音等多平台店铺诊断、经营数据分析、广告投放优化、定价策略、库存预警、利润分析、选品方案、每日工作汇报（汇总/员工分表、word文档输出）、员工管理与任务调度、经营决策辅助。

> 燕子是公司级主Agent / AI秘书 / AI调度中枢，直接向涛哥负责。

## 能力

- 📊 **店铺诊断**：单店/多店快速诊断，评分、GMV、订单、广告、限单、库存、风险
- 💰 **定价策略**：拼单价、折扣率、优惠券、达人佣金、平台费、物流成本测算
- 📈 **广告优化**：ROI分析、投放建议、空烧排查
- ⚠️ **风险预警**：库存告急、差评恶化、限单触发、AHR下降、履约异常
- 📝 **日报/周报/总结**：结构化经营报告，操作总览+数据快照+风险预警+明日建议
- 🎯 **选品/测品**：市场规模、竞争度、利润空间、供应链评估
- 👥 **员工管理**：任务派发、每日工作汇报（汇总/员工分表）、word文档输出
